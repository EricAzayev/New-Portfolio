Github: https://github.com/EricAzayev/letterbuddy

Letter Buddy is a hackathon app in the Data Track built to help kids improve their writing through a React frontend, FastAPI backend, and a home-made TensorFlow Character Recognition Machine Learning algorithm trained on the EMNIST dataset.

Letter Buddy differs from other grammar apps in that it offers AI feedback including character recognition scores, mistake analytics, and personalized stroke-order guidance to help children master the physical flow of handwriting alongside linguistic accuracy.
